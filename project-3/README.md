# Smart Course Recommendation System

## Overview
A content-based recommendation system that recommends courses based on user interests using TF-IDF Vectorization and Cosine Similarity. The system analyzes user preferences and suggests the most relevant courses with match scores and course details.

## Features
- User interest-based recommendations
- Difficulty level filtering
- TF-IDF Vectorization
- Cosine Similarity matching
- Top 5 course recommendations
- Match percentage display
- Matched skills identification

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

## Workflow
User Input → Difficulty Filtering → TF-IDF Vectorization → Cosine Similarity → Course Recommendations
